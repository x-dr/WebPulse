## 本地真实联通

使用项目专用开发 PostgreSQL 容器，数据库只监听 `127.0.0.1:5432`，应用与 Vite 分别监听本机 3000/5173。就绪检查读取真实数据库中的迁移名称及校验和；API 与 Vite 代理均实际返回 200。

真实联通检查在 1440、1024、768、390px 四种宽度均通过：应用连接正常、数据库已就绪、刷新可用、无横向溢出、无页面异常。初次截图过程中，构建触发了开发服务器热重启并造成短暂断连；最终在构建完成后使用稳定的 API 构建产物重跑，四种尺寸全部通过。

## TypeScript 7 与 Oxlint 升级（2026-11-04）

TypeScript 从 `5.9.3` 升至 `7.0.2`，Oxlint `1.91.0` 接替 ESLint 及 typescript-eslint；Prettier 保留。源码、tsconfig、SQL 和原设计快照未更改。依赖清单与锁文件均不再包含 ESLint 或 TS6 兼容包。

| ----------------------- | ------------ | ----------------------------------------------------------------------------------- |

| `pnpm lint`             | 通过         | `oxlint --deny-warnings .`，警告或错误均阻止通过                                    |

规则转换保留 85 个不同规则名称。关闭默认 `correctness` 分类后逐项显式配置规则，避免随分类默认值引入额外规则。`no-undef`、`no-useless-assignment` 虽属实验规则，仍显式启用以保留原有检查；TypeScript 文件的 `no-undef` 继续由编译器承担。

规则样例验证了未定义 JS 变量、无效赋值、显式 `any`、重复参数、旧式八进制字面量、合法 Node 全局变量、合法浏览器属性修改、只读浏览器全局变量赋值。预期错误均返回非零退出码，合法样例返回零；这些样例在临时目录执行，未添加到业务源码。

机器可读结果保存在 [toolchain-upgrade.json](verification/toolchain-upgrade.json)。本次未执行其他 CPU/操作系统架构、编辑器语言服务、生产容器或部署验收；未改变 M0–M5 的业务实现边界。
