# M3 米色后台与验收

日期：2026-11-06。状态：已完成本地实现与验收。阶段范围以 [实施计划](实施计划与进度.md) 和 [设计第 3、4 节](../design/WebPulse-项目技术文档.md#3-功能与页面需求) 为准。

## 页面与接口

| 页面                       | 已交付行为                                                                        | 使用接口                                                                               |
| -------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 登录                       | 管理员登录、错误提示、键盘提交、退出、失效后保留站点和日期                        | `/auth/login`、`/auth/session`、`/auth/logout`                                         |
| 总览 `/overview`           | 七项指标、同期比较、趋势、新老访客、来源/受访/入口 Top 8、暂定与冻结水位说明      | `/stats/overview`、`/stats/trend`、`/stats/visitors`、`/stats/sources`、`/stats/pages` |
| 来源 `/sources`            | 渠道筛选、来源域名及白名单 UTM 详情、稳定分页、计数/名称排序、范围占比            | `/stats/sources`                                                                       |
| 页面 `/pages`              | 受访/入口/退出、128 字路径搜索、20 条分页、排序、占比                             | `/stats/pages?mode=view/entry/exit`                                                    |
| 访客 `/visitors`           | 整个范围的新老访客、占比与 UV 趋势、浏览器身份口径                                | `/stats/visitors`、`/stats/trend?metric=uv`                                            |
| 站点 `/sites`              | 创建、列表、空站点引导                                                            | `GET/POST /sites`                                                                      |
| 设置 `/sites/:id/settings` | 资料、Origin、过滤规则、导航模式、SDK 代码与 CSP 提示、诊断、暂停/恢复            | `PATCH /sites/:id`、`GET /sites/:id/diagnostics`                                       |
| 保留设置                   | 先预览各层实际安全清理边界，输入站点名后确认更新                                  | `/sites/:id/retention-preview`、`PATCH /sites/:id/retention`                           |
| 删除与任务 `/jobs/:id`     | 输入站点名、取消、复用幂等键重试、受理后查看任务、5 秒轮询、显示 journal 等待状态 | `DELETE /sites/:id`、`GET /jobs/:id`                                                   |

以上路径均以 `/api/v1` 为 API 前缀。后台全部使用现有 M1/M2 API，无演示数据回退；本阶段未修改后端、迁移或采集协议；补齐 Vite 的 `/tracker.js` 开发代理，让设置页的同源 SDK 地址与管理 API 一起转发。

公开站点 ID 用于标识站点，不作为密钥。当前 PATCH 白名单不接受时区；设置页只读显示时区，创建时可指定。诊断接口尚未持久化拒绝原因计数，界面明确显示“暂不可用”，不会显示伪造的 0。

## 统计与交互约束

- 全局站点与日期通过 URL 共享，支持后退、前进和直接访问。今日、昨日、近 7/30 日和自定义日期均按站点时区计算；界面结束日含当天，发送 API 时加一个自然日，保持 `[start_date,end_date)`。限制 365 日；非法链接明确提示并回到站点今日。
- Query key 包含站点、日期、时区及分页/筛选参数。切换站点取消旧报表请求；查询使用 AbortSignal；刷新保留已有数据并显示“更新中”。401 清理敏感查询缓存并回到登录页；重新登录保留 URL 范围。
- CSRF 只保存在内存，密码提交后清空；管理 cookie 由服务端 HttpOnly 设置，未写入浏览器存储。写操作携带 CSRF，删除重试复用每站点幂等键。sessionStorage 仅保存非凭据的删除请求键。
- 七卡为最近 15 分钟活跃、IP、PV、UV、会话、跳出率和平均时长。活跃是查询时快照，不参与历史同期涨跌。会话计本期开始的会话；比率/时长只计已结束会话，时长注明估计，长时长完整展示。
- 跳出率变化同时显示相对变化和百分点；基期为 0 显示“—”，鼠标悬停说明原因。不可用值显示“—”及服务端原因，不以 0 替代。趋势缺失点不连线；真实 0 保留为 0。
- 来源/入口单位为会话，受访为 PV，退出只计已结束会话。表格显示全范围总计及本页外计数；筛选/排序重置分页。来源详情按完整渠道、域名和 UTM 维度查询，不采集搜索词。
- 日期范围 UV/IP 使用 API 精确值，不累加趋势点；新老访客以整个范围分类，不累加每日分类。
- 删除与保留策略有明确作用域、取消、确认和失败提示。删除响应失败后保留同一幂等键，成功后跳转任务页；任务页不依赖站点继续存在。删除不在前端宣称受理即完成。

## 视觉与可访问性

沿用设计的米色底、近白卡片、深色顶部细线、橙红趋势和绿色对比；1440px 七列指标、趋势 16:8、三列排行；1024px 4 列指标；768px 3 列指标及两列排行；390px 活跃通栏、其余两列、图表和排行单列。无远程字体、厚重阴影或渐变背景。

ECharts 6.0.0 按需引入折线、网格、Tooltip、ARIA 和 SVG 渲染器，并在报表需要时懒加载图表模块。折线不平滑、不跨缺失点连接，面积透明度 0.06；Tooltip 显示完整值及时区。用法参考 [ECharts 按需导入](https://echarts.apache.org/handbook/en/basics/import/) 和 [ARIA 官方说明](https://echarts.apache.org/handbook/en/best-practices/aria/)。

## 阶段边界

M3 是本地后台实现与验收，未提交、推送或部署。SSE、实时页与活跃卡实时跳转、生产静态资产托管/镜像、可信代理、角色分权、TLS、备份/独立删除清单在 M4；默认删除执行器仍停在 journal 闸门。实际线上采集时间、长期负载、故障恢复、安全加固和性能预算在 M4/M5 验收。当前图表懒加载后的入口 gzip 约 315kB、图表约 178kB，尚未验证目标机器上的弱网首屏性能。
