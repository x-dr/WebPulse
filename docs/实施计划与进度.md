# WebPulse 实施计划与进度

更新日期：2026-11-06。

## 当前范围

当前已完成工程初始化与 M0–M4 的本地实现及验收：管理员/站点 API、浏览器 SDK、采集/会话、统计报表、聚合冻结、保留清理、米色后台、实时 SSE、生产容器、独立删除清单及备份恢复已交付。沿用 `design/` 的 Fastify + TypeScript、React + Ant Design、PostgreSQL 17 和 pnpm workspace 选型。生产删除必须取得独立清单持久化确认；恢复必须重放完整清单并验证闸门。R01–R07 设计修订已完成；R08–R14 按阶段落实，完整保留窗口、长期负载、安全与崩溃矩阵仍在 M5。没有部署 VPS 或操作既有生产数据。

M0 设计冻结与 M1 业务验收分开记录。数据库初始迁移以参考 SQL 为基础，后续结构修订通过新迁移追加。保留 `design/reference/` 作为原始设计快照，应用迁移以 `apps/server/migrations/` 为维护源。
