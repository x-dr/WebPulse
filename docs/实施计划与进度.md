# WebPulse 实施计划与进度

更新日期：2026-11-03。

## 当前范围

本次完成工程初始化：可安装、可构建、可启动、可验证的开发骨架。沿用 `design/` 的 Fastify + TypeScript、React + Ant Design、PostgreSQL 17 和 pnpm workspace 选型。初始化前仓库仅有设计资料；现已有可运行工程骨架，统计业务尚未实现。设计评审 R01–R14 仍须逐项处理。

初始化不等于原计划 M0 设计冻结或 M1 采集完成。数据库初始迁移以参考 SQL 为基础，后续结构修订通过新迁移追加。保留 `design/reference/` 作为原始设计快照，应用迁移以 `apps/server/migrations/` 为维护源。
