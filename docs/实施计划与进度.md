## 工具链升级（2026-11-04 验收）

状态：已完成。TypeScript 固定为 `7.0.2`，用 Oxlint `1.91.0` 接替 ESLint / typescript-eslint，保留 Prettier 和已有 `tsc` 命令；不引入 TS6 兼容包。

1. `.oxlintrc.json` 保留 85 条规则和原有目录边界，显式启用 `no-undef`、`no-useless-assignment`；重复参数和旧式八进制字面量由 ESM 严格模式语法检查覆盖。浏览器全局变量使用内置环境配置。
2. 移除旧 lint 依赖及 `eslint.config.js`，更新锁文件；业务源码、tsconfig、SQL 和设计快照未修改。
3. 冻结依赖安装、lint、类型检查、四包构建以及 31 项既有测试通过；8 个规则样例及构建后 API 的两个健康接口通过。

详细结果及边界见 [验证记录中的工具链升级](初始化验证记录.md#typescript-7-与-oxlint-升级2026-11-04)和 [机器可读结果](verification/toolchain-upgrade.json)。该工具链升级本身未改变 M0–M5 范围；后续 M0 进展见上节。
