# M0 设计冻结与验收

日期：2026-11-04；设计版本：1.1.0。范围依据 [实施计划](实施计划与进度.md)：修订 R01–R07，冻结统计、并发、删除恢复契约，明确 R08–R14 落点。本次交付为设计基线与 SQL/锁协议验证；登录、站点 API、SDK、聚合 worker、删除执行器仍待 M1–M4 实现。

## 交付与决策

- [主技术文档](../design/WebPulse-项目技术文档.md)：同步修正受影响章节及里程碑，保持 19 章结构。
- [统计与采集契约](../design/统计与采集契约.md)：时间/幂等前置语义、禁用锁、导航判重、关闭互动、历史截止、替换式重算、独立冻结。
- [删除与覆盖契约](../design/删除与覆盖契约.md)：逻辑表字段、状态机、事务游标、逐层覆盖、删除清单、恢复闸门及迁移顺序。

冻结的是逻辑契约。已应用 `001_init.sql` 和原始 `design/reference/` 不修改；新业务字段和索引在对应阶段追加迁移。`metric_version=1` 仍适用，因为尚无对外业务统计数据；文档版本升为 1.1.0。原 UI/隐私基线沿用，不在 M0 扩展页面或产品范围。

R11 中取锁后的接纳时间、判重前禁止访客副作用、指纹字段和所有活动的顺序是 R01/R04 的必要前置，已一并明确；其实现及乱序回归仍归 M1。普通完整历史周期比较使用当前一致快照的最终会话口径；涉及部分末日的比较才对两侧统一使用历史关闭截止。

## R01–R07 可执行验收场景

以下为未来业务验收规范；**场景已冻结不代表业务测试通过**。本次实际执行的设计探针单列在文末。时间均由测试固定，日边界按指定站点时区计算。

| 编号  | 给定与动作                                                | 必须断言                                                         | 业务验收阶段 |
| ----- | --------------------------------------------------------- | ---------------------------------------------------------------- | ------------ |
| R01-A | 一次访问后停止写入，聚合已清脏；推进到桶结束 +12h30min    | 独立扫描冻结，不依赖新事件；到保留截止可清理                     | M2           |
| R01-B | 建站后连续无流量；冻结任务停机再重启                      | 从游标补零覆盖、不漏日；建站前不是完整零日                       | M2           |
| R01-C | 已到期但仍有未关闭会话、版本冲突或覆盖 gap                | 不冻结、不推进连续水位、不清理；修复后重试                       | M2           |
| R01-D | 午夜前排队、午夜后取锁；模拟超时事务及钟回拨              | 取锁后归属新日；超时不迟交；时钟异常暂停冻结                     | M1/M2        |
| R02-A | UTC 昨日 A 09:00、B 15:00 访问，比较截止 10:00            | 部分日 UV=1，不能返回全天 UV=2；恰好 10:00 PV 不计               | M2           |
| R02-B | A 在完整日和后一个部分日均访问                            | 合并范围 UV=1；新+老=UV，不能相加分段 UV                         | M2           |
| R02-C | 昨日 09:00 开始、11:30 才关闭，历史截止 10:00             | 会话计 1，已结束分母计 0；closed_at 恰好截止则计入               | M2           |
| R02-D | 23:55 开始、次日 00:10 PV、00:40 关闭                     | 会话归前日，PV 归各自日期；后日分母不包含该会话                  | M2           |
| R02-E | America/New_York：比较端 2026-03-08 02:30 不存在          | 映射 03:30（07:30Z）；dst_resolution=shift_forward，调整 3600 秒 | M2           |
| R02-F | America/New_York：比较端 2026-11-01 01:30 重复            | 取第一次 05:30Z，dst_resolution=earlier；一天仍按 25 小时边界    | M2           |
| R02-G | 部分日期明细已清理、身份快照缺失或历史会话不可用          | 相关指标及变化为 null+准确原因；完整日其他指标仍可用             | M2/M3        |
| R03-A | 跨任务轮次 `/product/123` → `/product/456`                | 两个 event ID、PV=2，上报与存储只有 `/product/:id`               | M1           |
| R03-B | 同 identity 连续 replaceState、同微任务多次 push/replace  | 每轮最终逻辑访问最多一次；独立 A→B→A 仍计三次                    | M1           |
| R03-C | 默认 query/hash 变化；显式 hash 模式变化；manual 模式调用 | 默认无新增、hash 模式清洗后上报、manual 无自动双报               | M1           |
| R03-D | BFCache pageshow/popstate；排除页后返回允许页；撤销同意   | 恢复只一次；回到允许页可计新 PV；原始 identity 不外泄            | M1           |
| R04-A | 已关闭会话的旧页面发送新 interaction ID                   | 409 session_expired；事件/互动计数/活动时间/冻结结果全不变       | M1           |
| R04-B | 已确认互动在关闭后同 ID 同载荷重试、随后改变载荷          | 前者 204 无副作用，后者 409 event_conflict                       | M1           |
| R04-C | open 会话依次测试 29:59、30:00、12h 边界                  | 29:59 可接纳；其余失效；失败请求不顺带关闭/修改会话              | M1           |
| R04-D | 关闭任务与新互动争锁；批次有重复 PV 与过期互动            | 结果按锁后状态决定；批次失败无部分写入                           | M1           |
| R04-E | SDK 缓存旧互动后收到 session_expired，生成 resume PV      | 旧互动丢弃，不转绑新 page_view_id；新会话未被伪造互动            | M1           |
| R05-A | 删除 `/a` 最后一次访问，剩余 `/b`                         | 重算后 `/a` 排行消失，总量与剩余事实相等                         | M2           |
| R05-B | 删除某来源全部会话，保留其他来源；随后清空整日            | 来源旧键消失；整日总量零、有覆盖，排行空且不是失败               | M2           |
| R05-C | 替换删除旧排行后制造失败；重试/并发更新脏版本             | 回滚保留旧完整版本；重试不重复；冲突不能清掉新脏标记             | M2           |
| R06-A | 每个删除 phase 的批次提交前后分别杀进程                   | 从已提交游标续跑、计数不重复；旧租约 worker 不能写入             | M2/M5        |
| R06-B | 部分日期清理后失败，空站点清理，扩大/缩短保留             | gap 不可用且可恢复；空站有覆盖；扩大不复活已删窗口               | M2           |
| R06-C | 完成整站删除，再查询 job、同幂等键重试                    | 结果仍可查，任务/清单/tombstone 未级联消失                       | M1/M2        |
| R06-D | 访客多 epoch 删除；共享 IP；某历史桶事实不足              | 完整 epoch 精确删除、保留共享 IP；依据不足 preflight 拒绝        | M2           |
| R06-E | 清单存储不可用或上传成功但本地确认前崩溃                  | 无破坏性批次；以 task ID 补确认不丢意图                          | M4           |
| R06-F | 恢复删除前快照；含快照前已受理但未完成的任务              | 开放前重放所有相关意图；删除数据不再提供查询                     | M4/M5        |
| R06-G | 恢复清单缺序、密钥缺失、旧汇总不可精确重建                | 缺序/缺密钥禁止开放；不可验证范围持久化封锁，不猜测扣减          | M4           |
| R06-H | 7 日轮转后仍留人工旧备份                                  | 清单和必要密钥继续保留；直到相关副本确认销毁                     | M4/M5        |
| R07-A | 采集持共享锁后暂停，管理员禁用等待                        | 禁用成功前旧采集已结束；成功后新请求均拒绝                       | M1           |
| R07-B | 请求入口预检为 true，禁用提交后才取得站点锁               | 锁内重新检查 false；不依据旧缓存写入                             | M1           |
| R07-C | 两个不同访客采集；另用 KEY SHARE 做负对照                 | SHARE 可并行；KEY SHARE 不能阻止 enabled 更新，禁止使用          | M1           |
| R07-D | 禁用锁超时、删除受理后尝试重新启用/报表/SSE               | 禁用失败回滚；删除维护期不能续写或读取部分结果                   | M1/M2/M4     |
